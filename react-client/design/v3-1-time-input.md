- 범위: SCH-03 일정 추가·SCH-06 일정 수정의 `복용 시간` 칸(`DoseTimesField`). 새 화면·API는 없음. 저장 계약 `HH:MM`은 그대로임.
- 추적: V3-SCHED-001(시각 +/−), V3-SCHED-002(숫자만 입력), V3-FL-19, V3-REQ-41·42.
- 목업: `design/mockups/v3-1/time-input/`(`sch03-a`·`sch03-b`·`error-a`·`error-b`, 캡처 `captures/*-focus.png`는 복용 시간 칸만 자른 것).
- 상태: A안으로 정함(DEC-020, 2026-11-02 PM "1A 2A 3A 4A 5A 6A"). 구현은 TASK-014. B안 목업·캡처는 비교 기록으로 남김.

## 후보

| 안 | 모양 | 장단점 |
| --- | --- | --- |
| A | 시각 칸 옆 `시 [−][+]` · `분 [−][+]` 아이콘 버튼 묶음. 360 폭에서는 시각 칸 아래 한 줄 | 같은 화면 `1회 개수`의 `[−] 1 [+]`와 같은 말투라 익숙함. 버튼 4개가 아이콘이라 무엇이 1시간·5분인지는 도움말과 화면 읽기 이름으로 알려 줌 |
| B | 시각 칸 아래 `−1시간` `+1시간` `−5분` `+5분` 글자 버튼 줄 | 버튼이 하는 일이 글자로 보임. 칸마다 한 줄이 늘어 세 칸이면 화면이 길어짐 |

## 동작

| 입력 | 결과 |
| --- | --- |
| 분 + / 분 − | 5분씩 바꿈. 55분에서 +면 다음 시 00분, 00분에서 −면 이전 시 55분. 5분 단위가 아닌 값(08:32)은 + 때 08:35, − 때 08:30처럼 가까운 5분 칸으로 맞춤 |
| 시 + / 시 − | 1시간씩 바꿈. 23시에서 +면 0시, 0시에서 −면 23시. 분은 그대로 |
| 버튼 길게 누름 | 0.5초 뒤부터 0.1초마다 반복. 손을 떼거나 포인터가 버튼 밖으로 나가면 멈춤. 반복한 뒤 손을 뗄 때는 한 번 더 바꾸지 않음 |
| 키보드 | 버튼에서 Enter·Space 한 번에 한 번 바꿈 |
| 글자 입력 후 칸 벗어남 | `830`·`0830`·`8:30`·`08:30`·`8시30분`·`8시` → `08:30`·`08:00`. 3자리는 H:MM, 4자리는 HH:MM으로 읽음. 칸을 벗어나지 않고 Enter로 저장해도 같은 규칙으로 읽어 보냄 |
| 칸이 비었거나 형식 오류일 때 +/− | 오류를 고치지 않고 기본 시각(그 칸의 아침 07:00·점심 12:00·저녁 17:00)에 한 번 더하거나 뺀 값으로 바꿈(점심 `2460`에서 시 + → `13:00`). 점심 기본은 2026-11-04에 11:00에서 12:00으로 바꿈(PM 결정, `v3-3-kakao.md` '등록·일정을 이어 말할 때와 답답한 말') |

## 표시와 전환

| 상태 | 화면 |
| --- | --- |
| 기본 | 기존 도움말 아래 `830처럼 숫자만 적어도 08:30으로 바뀌어요.`와 안별 버튼 설명 한 문장을 더함 |
| 형식 오류(`2460`, `25:00`, `08:61`, `아침`) | 칸을 벗어날 때 확인함(쓰는 중에는 띄우지 않음). 칸 빨간 테두리(`aria-invalid`), 목록 아래 `점심 시각을 00:00~23:59 사이로 적어 주세요. 830처럼 숫자만 써도 돼요.` 값은 지우지 않음. 두 칸 이상이면 `점심·저녁 시각을 …`. 저장 눌렀을 때 형식 오류 문구도 같음 |
| 형식 오류 중 저장 | `일정 저장` 잠금, 저장 버튼 위 `복용 시간을 고치면 저장할 수 있어요.`(버튼 `aria-describedby`) |
| 오류를 고침 | 쓰는 동안 바로 다시 확인해 맞는 값이 되면 오류 줄·저장 잠금이 바로 풀림. +/−로 바꿔도 풀림 |

- 버튼 이름: `아침 1시간 더하기`·`아침 5분 빼기`처럼 칸 이름과 양을 화면 읽기 이름으로 붙임. 버튼은 44px. 시·분 묶음은 `아침 시`·`아침 분` 그룹 이름을 가짐.
- 기존 `빼기` 버튼의 화면 읽기 이름은 `아침 1시간 빼기`와 헷갈리지 않게 `아침 시간 빼기`에서 `아침 복용 시간 빼기`로 바꿈. 보이는 글자는 그대로 `빼기`임.
- 바뀐 시각은 칸 값으로만 보이며 매번 따로 읽어 주지 않음(칸이 바뀐 값을 그대로 가짐).
- SCH-06 일정 수정도 같은 칸·잠금을 씀(저장 버튼 `수정 저장`).
- 이미 있는 `빼기`·`시간 추가`·하루 1~3번 규칙은 그대로임.

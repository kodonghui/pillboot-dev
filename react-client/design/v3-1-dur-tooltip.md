# v3 1차 · 금기 표시 설명(TASK-017)

- 범위: CHT-02 답변의 금기 카드(`ChatAnswer`의 `DurCard`) 종류 배지(병용금기·연령금기·임부금기·노인주의). 새 화면·API는 없음. 설명 글은 화면에 고정해 둠.
- 추적: V3-COMMON-002, V3-FL-21, V3-REQ-44. 금기 종류 이름은 `src/chatInfo.js`의 `durTypes`와 같음.
- 목업: `design/mockups/v3-1/dur-tooltip/`(`closed-a`·`open-a`·`closed-b`·`open-b`, 캡처 360은 금기 카드 부분만 자른 것).
- 상태: 후보 2안. PM 선택 전이며 선택 전에는 프론트 코드를 바꾸지 않음.

## 설명 글(두 안 공통)

| 종류 | 설명 |
| --- | --- |
| 병용금기 | 함께 먹으면 부작용이 커지거나 약효가 달라질 수 있어 같이 먹지 않도록 정한 약 조합이에요. |
| 연령금기 | 특정 나이(주로 어린이)에게 쓰면 위험할 수 있어 그 나이에는 먹지 않도록 정한 약이에요. |
| 임부금기 | 임신 중에 먹으면 태아에게 해로울 수 있어 피해야 하는 약이에요. |
| 노인주의 | 65세 이상 어르신이 먹을 때 부작용이 더 잘 생길 수 있어 주의가 필요한 약이에요. |

- 설명은 일반적인 뜻이며 이 사용자에게 맞는지는 판단하지 않음. A안 상자 끝에 `일반적인 뜻이에요. 내 경우는 의사·약사에게 확인해 주세요.`를 둠.

## 후보

| 안 | 모양 | 닫기 | 장단점 |
| --- | --- | --- | --- |
| A | 배지 끝에 ⓘ 아이콘, 누르면 배지 바로 아래 작은 상자(제목 `임부금기란?`, 설명, 닫기 ×) | ×·Esc·바깥 누름. 닫으면 포커스는 배지로 | 명세(V3-COMMON-002)의 '띄움·바깥 누름·Esc로 닫힘'과 그대로 맞음. 상자가 카드 글을 잠시 가림 |
| B | 배지 끝에 ⌄ 아이콘, 누르면 카드 제목 아래 흰 줄로 설명이 펼쳐짐(⌃) | 배지를 다시 누름(Esc도 닫음) | 아무것도 가리지 않고 화면이 흔들리지 않는 위치에 남음. '바깥 누름으로 닫힘'은 맞지 않아 B안이면 명세 문장을 '다시 누르면 접힘'으로 고쳐야 함 |

## 표시와 전환

| 상태 | 화면 |
| --- | --- |
| 닫힘 | 배지가 버튼이 됨(`aria-expanded="false"`, 이름 `임부금기 설명 보기`). 모양은 지금 배지와 같고 아이콘만 더함. 누르는 범위는 위아래로 넓혀 44px |
| 열림 | A: 상자 `role="dialog"`, 포커스를 상자 닫기 버튼으로. B: 설명 줄에 `id`를 두고 배지 `aria-controls`로 이음 |
| 한 카드에 열린 설명은 하나 | 다른 배지를 열면 앞의 것은 닫힘 |

- 마우스를 올리기만 해서 여는 방식은 쓰지 않음(휴대폰).
- 금기 조회 실패 카드·일부 확인 못 함 안내에는 종류 배지가 없으므로 바뀌지 않음.

| 종류 | 설명 |
| --- | --- |

## 표시와 전환

| 상태 | 화면 |
| --- | --- |
| 닫힘 | 배지가 버튼이 됨(`aria-expanded="false"`, 이름 `임부금기 설명 보기`). 모양은 지금 배지와 같고 아이콘만 더함. 누르는 범위는 위아래로 넓혀 44px |
| 열림 | A: 상자 `role="dialog"`, 포커스를 상자 닫기 버튼으로. B: 설명 줄에 `id`를 두고 배지 `aria-controls`로 이음 |
| 한 카드에 열린 설명은 하나 | 다른 배지를 열면 앞의 것은 닫힘 |

- 마우스를 올리기만 해서 여는 방식은 쓰지 않음(휴대폰).
- 금기 조회 실패 카드·일부 확인 못 함 안내에는 종류 배지가 없으므로 바뀌지 않음.
- A안 구현에서 정한 것: 배지를 다시 눌러도 닫힘. Tab으로 상자 밖으로 나가면 닫히고 포커스는 옮겨 간 곳에 둠(배지로 되돌리지 않음). 바깥 누름도 같음.
- 넘침 처리: 상자는 배지 왼쪽 끝에 맞춰 열고, 오른쪽 끝이 화면 끝에서 16px 또는 상자를 감싼 대화 목록 안쪽 끝에서 8px을 넘으면 넘친 만큼 왼쪽으로 옮김. 상자 폭은 `min(320px, 100vw − 96px)`.

## 검증 범위

- 목업 캡처: 360·1280 폭에서 A·B 닫힘·열림(임부금기)을 찍어 봄. 1280은 대화방 화면 높이(900)만, 360은 금기 카드 부분만 자름.
- 구현(TASK-018): 가짜 API 대화방(`/chat/7`, 임부금기·병용금기 카드)에서 확인함. 1280 폭: 누르면 상자 열림(`role="dialog"`, 제목 `임부금기란?`로 이름, `aria-expanded="true"`, 포커스 `설명 닫기`), Esc·× 로 닫으면 포커스가 배지로 돌아옴, 키보드 Enter로 열고 닫기, Tab으로 나가면 닫히고 다음 배지로 감, 바깥 누름으로 닫힘, 열린 채 다른 배지를 누르면 앞 상자는 닫히고 새 상자만 열림. 닫기 버튼 44×44, 배지 누름 범위 위아래 10px 넓힘. 430 폭: 제목 줄 오른쪽 병용금기 상자가 왼쪽으로 옮겨져 대화 목록 안에 들어옴(가로 넘침 없음). 360 폭: 배지가 줄을 바꿔 상자가 옮김 없이 들어옴, 문서 폭 360. `npm run lint`·`npm run build` 통과.
- 아직 안 한 것: 연령금기·노인주의 카드(가짜 데이터에 없음, 같은 부품), 열린 채 화면 폭을 바꿀 때 위치 다시 맞추기(하지 않음), 실제 서버 응답, 화면 읽기 낭독, 실제 터치 기기.

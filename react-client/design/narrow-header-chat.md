# 좁은 화면(720px 이하) 헤더와 약봉이 대화방

- 범위: 로그인 후 모든 화면 위 헤더(AppHeader)와 약봉이 대화방(CHT-02)의 720px 이하 배치. 넓은 화면과 로그인 전 헤더는 바꾸지 않음.
- 왜: PM 말 "그리고 모바일에서 UXUI 엉망이야"(2026-11-04 Claude Code 대화)와 함께 보낸 아이폰 캡처 3장(공개 웹, 로그인 후 약 목록·약봉이).
- 캡처에서 본 것
  1. 주 메뉴 글자가 줄을 바꿈(`약/목록`, `복용/달력`, `약봉/이`, `설/정`). 좁은 화면에서 메뉴를 가로 스크롤로 바꿨지만 링크가 줄어들며 글자가 꺾임.
  2. 헤더가 로고 / 관리할 사람·닉네임 / 로그아웃 / 메뉴 네 줄로 쌓여 화면 위쪽을 많이 차지함.
  3. 대화방 머리(제목 아래 줄로 내려간 `약 등록`, 안내 두 줄)와 입력창(사진·입력칸·보내기, 글자 수, 면책 안내 상자)이 커서 대화 내용이 몇 줄만 보임. 입력칸이 좁아 안내 글자가 `질문을 입력해 주`에서 잘림.
- API: 없음. 목업: 따로 만들지 않음(목업에 좁은 화면 규칙이 없음, `components/AppHeader/README.md` '크기'만 있음). 구현 캡처로 확인함.
- 추적: `components/AppHeader/README.md`(크기), CHT-02 대화방(`src/components/ChatRoom.jsx`·`ChatComposer.jsx`).

## 헤더

| 줄 | 내용 |
| --- | --- |
| 첫 줄 | 왼쪽 로고. 오른쪽에 관리할 사람(그 화면에서 보일 때만)과 로그아웃 |
| 둘째 줄 | 주 메뉴 5개(홈 · 약 목록 · 복용 달력 · 약봉이 · 설정). 글자는 줄을 바꾸지 않고, 다 들어가지 않으면 가로로 밀어 봄 |

- 관리할 사람: `관리할 사람` 글자는 화면에서 숨기고 점 · 이름 · ▾만 보임(버튼 이름에는 남아 화면 읽기가 그대로 읽음). 이름이 길면 6자쯤에서 말줄임표.
- 닉네임(`고동희님`)은 숨김.
- 로그아웃: 아이콘만 보이는 44×44 버튼. 이름 `로그아웃`은 화면 읽기에 남음. 누르면 지금처럼 확인창.
- 첫 줄에 다 들어가지 않으면 관리할 사람 · 로그아웃 묶음이 통째로 다음 줄 오른쪽으로 내려감(하나만 떨어지지 않음).
- 메뉴 링크는 좌우 안쪽 10px, 사이 0, 높이 44px. 지금 메뉴 밑줄은 그대로.

## 약봉이 대화방(CHT-02)

| 자리 | 내용 |
| --- | --- |
| 대화방 높이 | 화면 높이에서 위아래 8px씩 뺌(넓은 화면 24px). 대화방을 열면 대화방 위가 화면 위 8px에 오도록 페이지를 내림 |
| 머리 | 제목과 `약 등록`을 한 줄에 둠. 제목이 길면 한 줄에서 말줄임표. 안쪽 위아래 16px, 제목 줄과 안내 사이 6px |
| 입력 줄 | 사진 버튼(52×52) · 입력칸 · 보내기(아이콘만, 52×52). 사이 8px. `보내기` 이름은 화면 읽기에 남음 |
| 면책 안내 | 상자(배경 · 테두리 · 안쪽 여백) 없이 안내 아이콘과 글만. 글자 크기(15px)와 안내 글자색, 문구는 그대로 |
| 입력창 안쪽 | 위 12px, 아래 16px, 입력 줄과 면책 안내 사이 10px |

- 대화방 목록은 지금처럼 대화방 위에 둠. 대화방을 열면 페이지가 대화방 자리로 내려가 대화방이 화면을 채움(지금 규칙).
- 넓은 화면(721px 이상)은 그대로임.

## 검증 범위

- 확인함(2026-11-04, Vite 개발 서버 + 가짜 API 예시 데이터, 로그인 상태)
  - 390×844 약 목록: 헤더 두 줄(로고 · 관리할 사람 · 로그아웃 / 메뉴), 메뉴 글자 줄바꿈 없음.
  - 360×740 홈: 헤더 높이 117px(첫 줄 로고 · 관리할 사람 113px · 로그아웃 44×44, 둘째 줄 메뉴 328px에 다 들어가 가로 스크롤 없음), 메뉴 5개 모두 높이 44px 한 줄, 문서 폭 360(가로 넘침 없음). 관리할 사람 · 설정 드롭다운이 화면 안(16~344px)에 열림.
  - 360×740 약봉이 대화방(`/chat/7`): 대화방 높이 724px(화면 − 16px), 머리 128px(제목 · `약 등록` 한 줄), 대화 내용 403px, 입력창 191px, 입력칸 안내 `질문을 입력해 주세요`가 다 보임, 보내기 52×52, 면책 안내 상자 없음. 대화방 자리로 내리는 부드러운 스크롤은 미리 보기 창에서 끝까지 가지 않아 손으로 같은 자리(대화방 위 8px)로 옮겨 확인함.
  - 1280×800: 닉네임 · `관리할 사람` · `로그아웃` · `보내기` 글자, 면책 안내 테두리, 대화방 높이(화면 − 48px)가 그대로임.
- 아직 안 한 것: 실제 아이폰 사파리(주소 표시줄 · 화면 키보드가 올라온 상태), 화면 읽기 낭독, 다크 모드.

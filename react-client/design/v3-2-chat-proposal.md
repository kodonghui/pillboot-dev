- 범위: CHT-02 상담 화면. 등록 요청·처방전 사진 답변 말풍선 안의 제안 카드, 입력창 왼쪽 사진 보내기 버튼, 사진을 읽는 동안의 기다림 말풍선. 일정 제안 카드(V3-CHAT-007)는 `v3-2-chat-schedule.md`(TASK-030)에서 정함.

## 표시와 전환

| 상태·응답 | 표시 |
| --- | --- |
| 대기(만료 전) | 고르는 카드 |
| 마감 시각이 지남(화면을 열어 둔 채) | `expiresAt`에 맞춰 화면에서 바로 시간이 지난 카드로 바꿈(서버를 다시 부르지 않음) |
| `넣기`를 누름 | 버튼 `넣는 중…`, 카드 전체 비활성. 다른 답을 보내는 중이어도 누를 수 있음(제안 확정은 질문 진행 표식과 따로임) |
| 200 확정 | 결과 카드: 체크 원 + `약목록에 N개를 넣었어요`, 넣은 약 목록, `15:47 확정 · 고르지 않은 M개는 넣지 않았어요.`(M=0이면 뒷부분 없음), `약목록에서 복용 시각 정하기`(약목록으로 이동) |
| `취소` → 200 취소 | 닫힌 카드: 금지 아이콘 + `취소했어요`, `14:03에 취소해서 약목록에 아무것도 넣지 않았어요.`, `후보: 이름 · 이름 외 N개`. 확인 창은 두지 않음(아무것도 저장하지 않고 다시 말하면 새 카드가 옴) |
| `취소`를 누름 | 카드 전체 비활성, `취소` 버튼에 도는 아이콘(글은 그대로) |
| `취소` → 409 `PROPOSAL_ALREADY_CONFIRMED` | 돌려받은 카드를 결과 카드로 보이고 위에 `다른 화면에서 이미 넣은 카드라 취소하지 않았어요.` |
| `취소` → 409 `PROPOSAL_EXPIRED` · 404 | 만료는 닫힌 카드, 404는 확정과 같은 빨간 안내 |
| `취소` → 503·연결 끊김 | 버튼 위 빨간 안내 `지금은 취소하지 못했어요. 잠시 뒤 다시 눌러 주세요.` 이미 취소된 카드를 다시 취소해도 200이라 다시 읽지 않음 |
| 만료(읽을 때·409 `PROPOSAL_EXPIRED`) | 닫힌 카드: 시계 아이콘 + `고를 수 있는 시간이 지났어요`, `카드는 30분 동안만 쓸 수 있어 16:15에 끝났어요. 약목록에 아무것도 넣지 않았어요. 넣으려면 약 이름을 다시 보내 주세요.`, 후보 요약 |
| 409 `PROPOSAL_ALREADY_CONFIRMED` | 돌려받은 카드(처음 확정 결과)를 결과 카드로 보이고 위에 `다른 화면에서 이미 넣은 카드예요. 더 넣지 않았어요.` |
| 409 `PROPOSAL_CANCELLED` | 돌려받은 카드를 닫힌 카드로 보임 |
| 409 `CONFLICT` | 카드는 대기 그대로이고 돌려받은 항목으로 바꿈. 새로 '이미 등록됨'이 된 고른 줄은 고름을 풀고 빨간 테두리, 버튼 위 빨간 안내 `고른 약 중 ‘이름’이 그사이 약목록에 들어가 있어서 아무것도 넣지 않았어요. 나머지를 확인하고 다시 넣어 주세요.`(여러 개면 `‘이름’·‘이름’`, 조사는 마지막 이름에 맞춤) 버튼 수는 남은 고름으로 다시 셈 |
| 400 | 화면이 막는 경우라 오지 않아야 함. 오면 버튼 위 빨간 안내로 서버 문구를 보이고 고름은 그대로 둠 |
| 404 | 버튼 위 빨간 안내 `이 카드를 찾을 수 없어요. 대화를 다시 열어 주세요.` |
| 503·연결 끊김 | 버튼 위 빨간 안내 `지금은 약목록에 넣지 못했어요. 잠시 뒤 다시 눌러 주세요.` 고름은 그대로 둠(서버가 저장했는지 모르므로 5xx·응답 없음이면 `GET /api/chat-proposals/{id}`로 다시 읽어 그 상태를 보임. 개발 프록시·앞단은 끊김을 502·504로 바꿔 줌, TASK-031) |
| 401 | 기존 로그인 만료 처리 |

- 상담 기록을 다시 열면 카드는 서버의 지금 상태(대기·확정·취소·만료)로 보임. 대기 카드의 '이미 등록됨'은 읽는 때 약목록 값임.
- 확정 뒤 금기 정보 미리 받기는 서버가 함. 카드에는 따로 보이지 않음.

## 읽어 주기·접근

- 카드는 제목으로 이름 붙인 구역. A안은 목록 전체가 하나의 묶음(숨긴 제목 `약목록에 넣을 약`)과 체크 상자, B안은 이름마다 묶음 제목(`‘이름’에서 찾은 약 · 하나 고르기`)과 라디오.
- '이미 등록됨' 줄은 고를 수 없음을 글자로 알림. 함량 배지는 아이콘과 글자를 함께 씀. 충돌 줄은 빨간 테두리와 `이미 약목록에 있어요` 글자를 함께 씀(색만으로 나누지 않음).
- 결과 카드·닫힌 카드로 바뀔 때 제목을 `role="status"`로 읽고, 오류 안내는 `role="alert"`.
- 사진 버튼과 고르는 칸·버튼은 44px 이상.

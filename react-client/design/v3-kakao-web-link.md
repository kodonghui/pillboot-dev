## PRF-06 카카오톡 연결

머리: 화면 제목 `카카오톡 연결`, 뒤로 가기 `프로필 관리로`(PRF-02·03과 같은 말). 머리말 메뉴는 `설정`을 지금 메뉴로 보이고(`/profiles`·`/notifications`처럼), 관리할 사람(PRF-04)은 숨김(계정 단위 화면이라).

### 알리는 것

카드 제목 `카카오톡에서도 이 계정의 프로필 약으로 답해 드려요`, 목록:

- `연결한 카카오톡은 이 계정의 모든 프로필(엄마·아빠 …)의 약목록·복약 일정·출생연도·성별·임신 여부를 볼 수 있어요. 카톡에서 ‘프로필 바꾸기’로 골라요.`
- `가족 본인의 카카오톡에 이으면 그 가족도 이 계정의 모든 프로필 약을 볼 수 있어요.`
- `카톡에서 한 상담은 이 계정의 상담 기록에 남아, 이 계정으로 로그인한 사람은 누구나 볼 수 있어요.`
- `카톡 대화는 카카오 서버를 거쳐요. 휴대폰을 같이 쓰는 사람이 카톡에서 약 이름을 볼 수 있어요.`
- `카톡에서 확정한 약 등록·일정 바꾸기는 그 프로필에 바로 저장돼요.`
- `카톡으로 복약 알림은 보내지 않아요. 알림은 지금처럼 웹 푸시로 와요.`
- `언제든 이 화면이나 카톡 ‘연결 끊기’로 끊을 수 있어요. 끊어도 약목록·상담 기록은 지워지지 않아요.`

확인란 `위 내용을 확인했어요`(누를 수 있는 자리 44px 이상). 안내 판 번호는 `KAKAO-LINK-1`(서버가 코드·연결에 남김).

| 낡음 | 코드 보임 상태에서는 5초마다 목록을 다시 읽고, 연결이 늘면 코드를 지우고 `카카오톡과 연결됐어요.` 알림과 함께 목록을 보임. 끊기에 성공하면 그 전에 시작한 다시 읽기의 답은 버림(끊은 줄이 되살아나지 않게). 늦게 온 앞 읽기의 답도 버림. 화면을 떠나거나 시간이 지나거나 연결되면 다시 읽기를 멈춤. 다른 창에 갔다 돌아오면 한 번 다시 읽음(카톡에서 끊은 경우) |

### 인사말과 도움말: 할 수 있는 것과 명령(PM 요청, 2026-11-04)

PM 말씀 "그 카카오톡에서 약봉이 켜면 인사말 하고, 사용 가능한 기능 및 가능한 명령어를 적어줘 핵심을."(2026-11-04, Claude Code 세션)에 따라 정함.

카카오가 인사를 보낼 수 있는 때(2026-11-04 확인):
- 봇 인사(다리의 `ENTRANCE`·`CHAT_JOIN`)는 그 사람이 채팅방에 **처음** 들어올 때 한 번만 옴. 카카오 고객센터는 봇이 연결된 채널이면 채팅방에 처음 입장할 때 봇 웰컴블록이 나온다고 씀. 챗봇 관리자센터 도움말은 웰컴블록이 사용자에게 최초 한 번만 간다고 씀.
- 채널을 친구로 추가하기만 하면 봇 인사가 아니라 채널 관리자센터의 '웰컴메시지'가 나감(400자, 버튼 2개까지).
- 대화를 지우고 채팅방을 다시 열면 아무 이벤트도 오지 않음. 2026-11-04 14:28·15:19에 다시 열었을 때도 오지 않았음. 그래서 다시 열 때 인사는 할 수 없고, 그때는 `/`나 `도움말`을 보내면 같은 목록이 옴.

**시작 안내**(연결 전 첫 메시지·처음 들어옴·연결 전 `도움말`·`/`. 말풍선 하나, 다음 말풍선은 그 단계 질문)

### `/`를 칠 때 뜨는 명령 목록(카카오 봇 명령어, 2026-11-04)

PM 말씀 "/ 쳤을때 뭐 나오게 못하는지 알아봐바. 진짜 못하면 나한테 보고해줘"(2026-11-04, Claude Code 세션)에 따라 조사하고 정함.

- 카카오톡 봇 API에는 명령어 목록과 봇 도움말이 있음.
  - 명령어 목록은 `GET /v1/bot/commands`로 보고, `POST /v1/bot/commands/update`로 목록 전체를 바꿈(30개까지). 한 명령은 이름 `buttonName`과 설명 `description`으로 이뤄짐.
  - 봇 도움말은 `GET /v1/bot/guide`로 보고, `POST /v1/bot/guide/update`로 `contents`를 바꿈.
  - 공식 문서는 공개돼 있지 않음. 공개 래퍼(`punch5545/KakaoTalk-Bot-Wrapper`의 `client.ts`·`types.ts`)에서 확인함.
  - 우리 봇 토큰으로 두 GET을 불러 보니 200이었음(2026-11-04). 명령은 0개(`{"utterances":[]}`)였고, 도움말은 카카오 기본 문구 `🤖 저와 함께 이런 것들을 할 수 있어요.`였음. 그래서 `/`를 쳐도 아무것도 안 뜬 것으로 봄.
- 등록할 명령(이 순서):

| 이름 | 설명 |
| --- | --- |
| `내 약` | 등록된 약 목록 보기 |
| `새 대화` | 앞 대화를 잇지 않고 새로 시작하기 |
| `도움말` | 할 수 있는 것과 명령 보기 |
| `로그인` | 필받음 웹 계정과 잇는 방법 보기 |
| `프로필 바꾸기` | 다른 가족 프로필 약으로 묻기(웹 연결 뒤) |
| `연결 끊기` | 웹 계정과의 연결 끊기(웹 연결 뒤) |

- 봇 도움말: `💊 약봉이와 이런 것들을 할 수 있어요. 약 질문은 그냥 보내 주세요.`
- 명령을 고르면 카톡이 `내 약`이나 `/내 약`을 보내는데, 둘 다 같은 명령으로 받음(위 '로그인·로그아웃 말'). 어느 글이 오는지와 목록이 어떻게 보이는지는 등록한 뒤 PC 카톡에서 확인해 여기에 적음.
- 명령과 봇 도움말 글은 다리 `yakbong/texts.py`의 `BOT_COMMANDS`·`BOT_GUIDE`에 둠. 등록은 `bash deploy/yakbong.sh admin commands apply`, 확인은 `admin commands`로 함.

**결과(2026-11-04): 약봉이 채팅방(채널채팅)에서는 `/` 목록을 띄울 수 없음**
- 등록함: 다리 PR #18 브랜치의 `admin commands apply`를 서버에서 실행함. 카카오가 `명령 6개`와 새 봇 도움말을 돌려줌. 카카오는 명령마다 보내는 글을 명령 이름 그대로(`내 약` 등) 둠.
- PC 카톡의 약봉이 채팅방에서 `/`를 쳤을 때(붙여 넣기와 `/` 키 누름 둘 다) 목록이 뜨지 않음. 채팅창 그림과 둘레 화면 그림 모두 같았음.
- 카카오 디벨로퍼스 봇 문서를 Aside가 로그인한 채 공식 검색으로 읽음. 문서 본문은 '페이지를 찾을 수 없습니다'로 열리지 않아 검색 요약의 원문을 옮김.
  - 명령어(`docs/ko/bot/common#command`): "사용자에게 추천할 명령어가 있다면 최대 30개까지 등록할 수 있습니다. 명령어 전체 수정 API로 명령어를 등록합니다. 단, 채널채팅은 퀵리플라이를 이용합니다."
  - 도움말(`#guide`): "도움말을 등록하여 봇이 제공하는 기능을 자세히 설명할 수 있습니다. 단, 채널채팅은 지원하지 않습니다. 등록한 도움말은 채팅방 우측 상단 메뉴(☰) > [챗봇 beta]에서 개별 봇을 선택하면 확인할 수 있습니다."
  - 채팅방(`#chat-room`): 봇 API를 쓰는 채팅방은 채널채팅·일반채팅·오픈채팅·팀채팅이고, 나와의채팅과 비밀채팅은 지원하지 않음.
  - 카톡설명서(talktips.kakao.com/content/84): `/`로 명령을 고르는 것은 ☰ → '챗봇'으로 들인 일반채팅(카톡 v25.4.0 이상)·팀채팅(v10.7.0 이상)의 기능임.
- 그래서 채널채팅에서 명령을 보이는 방법은 퀵리플라이(빠른 답장 단추)뿐임. 다리는 이미 `도움말`·연결됨 등에 퀵리플라이를 붙이고, 형식(`label`·`action: message`·`messageText`)도 공개 래퍼와 같음. 그런데 PC 카톡에서도, 휴대폰 카톡에서도 단추가 보이지 않음(휴대폰은 PM "3. 안보여", 2026-11-04). 까닭은 아직 모름. 그래서 빠른 답장으로 고르게 하는 곳은 모두 글로도 받아야 함(`v3-3-kakao.md` '버튼이 보이지 않을 때').
- 등록한 명령 6개와 봇 도움말은 그대로 둠. 채널채팅에는 보이지 않고, 약봉이를 일반채팅에 들이지 않으므로 보이는 곳이 없음. 다리는 단체방(일반채팅)에서 약 정보를 답하지 않음.
- 지금 채널채팅에서 쓸 수 있는 것: `/`나 `도움말`을 보내면 명령 목록이 옴(위 '로그인·로그아웃 말').

## PRF-06 카카오톡 연결

머리: 화면 제목 `카카오톡 연결`, 뒤로 가기 `프로필 관리로`(PRF-02·03과 같은 말). 머리말 메뉴는 `설정`을 지금 메뉴로 보이고(`/profiles`·`/notifications`처럼), 관리할 사람(PRF-04)은 숨김(계정 단위 화면이라).

### 알리는 것

카드 제목 `카카오톡에서도 이 계정의 프로필 약으로 답해 드려요`, 목록:

- `연결한 카카오톡은 이 계정의 모든 프로필(엄마·아빠 …)의 약목록·복약 일정·출생연도·성별·임신 여부를 볼 수 있어요. 카톡에서 ‘프로필 바꾸기’로 골라요.`
- `가족 본인의 카카오톡에 이으면 그 가족도 이 계정의 모든 프로필 약을 볼 수 있어요.`
- `카톡에서 한 상담은 이 계정의 상담 기록에 남아, 이 계정으로 로그인한 사람은 누구나 볼 수 있어요.`
- `카톡 대화는 카카오 서버를 거쳐요. 휴대폰을 같이 쓰는 사람이 카톡에서 약 이름을 볼 수 있어요.`
- `카톡에서 확정한 약 등록·일정 바꾸기는 그 프로필에 바로 저장돼요.`
- `카톡으로 복약 알림은 보내지 않아요. 알림은 지금처럼 웹 푸시로 와요.`
- `언제든 이 화면이나 카톡 ‘연결 끊기’로 끊을 수 있어요. 끊어도 약목록·상담 기록은 지워지지 않아요.`

확인란 `위 내용을 확인했어요`(누를 수 있는 자리 44px 이상). 안내 판 번호는 `KAKAO-LINK-1`(서버가 코드·연결에 남김).

| 상태 | 화면 |
| --- | --- |
| 불러오는 중 | 제목과 카드 자리 표시. 버튼은 누를 수 없음 |
| 코드 받기 전 | 알리는 것, 확인란, 버튼 `연결 코드 받기`. 확인란을 고르기 전에는 버튼을 누를 수 없고 버튼 위에 `확인란을 골라야 코드를 받을 수 있어요.` |
| 코드 보임 | 큰 코드 `7K3Q-M9XA`(고정폭 글꼴, `screen-hero` 크기. 고정폭 글꼴 토큰이 없어 시스템 고정폭 글꼴을 씀. 360 폭에 맞게 글자 사이를 좁게 둠), 아래 `9분 41초 남음`. 버튼 `코드 복사`(복사하면 2초 동안 `복사했어요`). 순서 `1. 카카오톡에서 ‘약봉이’ 채널 대화방을 열어요` `2. 이 코드를 그대로 보내요`. 경고 `코드는 10분 동안 한 번만 쓸 수 있어요. 다른 사람에게 알려 주지 마세요.` 버튼 `새 코드 받기`와 그 위 설명 `새 코드를 받으면 지금 코드는 못 써요.` |

| 끊기 확인 창 | 제목 `카카오톡 1 연결을 끊을까요?`, 본문 `이 카카오톡 약봉이는 이 계정의 약을 더 쓰지 않아요. 약목록과 상담 기록은 지워지지 않아요.`, 버튼은 확인 창 부품 순서대로 `취소`·`끊기`. 끊으면 그 줄이 사라지고 `연결을 끊었어요.` 알림 |
| 오류 | 목록 읽기 실패: `연결 상태를 불러오지 못했어요.`와 `다시 시도`. 목록을 한 번도 읽지 못했으면 `연결 코드 받기`를 누를 수 없고 버튼 위에 `연결 상태를 불러온 뒤 코드를 받을 수 있어요.`(코드를 받을 때 있던 연결과 견주어야 새 연결을 알아봄). 코드 받기 실패(서버 오류·네트워크): 버튼 아래 `코드를 받지 못했어요. 잠시 뒤 다시 눌러 주세요.` 429: `코드를 너무 자주 받았어요. 10분 뒤 다시 받아 주세요.` 409 `KAKAO_LINK_LIMIT`: 5개 안내로 바꿈. 끊기 실패: 창 안에 `끊지 못했어요. 다시 눌러 주세요.` 끊기 404: 이미 끊긴 것으로 보고 목록을 다시 읽음 |
| 권한 | 401은 CMN-03(지금 전역 처리) |
| 낡음 | 코드 보임 상태에서는 5초마다 목록을 다시 읽고, 연결이 늘면 코드를 지우고 `카카오톡과 연결됐어요.` 알림과 함께 목록을 보임. 끊기에 성공하면 그 전에 시작한 다시 읽기의 답은 버림(끊은 줄이 되살아나지 않게). 늦게 온 앞 읽기의 답도 버림. 화면을 떠나거나 시간이 지나거나 연결되면 다시 읽기를 멈춤. 다른 창에 갔다 돌아오면 한 번 다시 읽음(카톡에서 끊은 경우) |

- 코드는 화면에만 보이고 주소·저장소(localStorage·sessionStorage)·개발 로그에 넣지 않음. 화면을 새로 고치면 코드는 다시 보이지 않고 `연결 코드 받기`만 있음(서버도 원문을 다시 주지 않음).

## CHT-01·02 `카톡` 꼬리표(Q5 B안)

- CHT-01 상담 목록 줄 제목 옆에 `카톡` 꼬리표(보조 배지, `channel`이 `KAKAO`인 방). CHT-02 대화방 머리 제목 아래에 `카톡에서 시작한 대화`.
- 웹에서 그 대화방에 이어 물어도 됨(같은 상담방). 꼬리표는 글자로 씀(색만으로 가르지 않음).

## 카톡 말풍선

### 시작 안내에 더하는 줄(V3-KAKAO-001)

지금 시작 안내(`texts.GUIDE`)의 둘째 점 앞에 한 줄을 넣고, 운영자 줄과 끝 줄을 좁힘.

| 더하는 줄 | 운영자 줄 | 끝 줄 |
| --- | --- | --- |
| `· 필받음 웹 회원이면 웹 ‘프로필 관리’ → ‘카카오톡 연결하기’에서 받은 연결 코드 8자를 보내 주세요. 그 계정의 프로필 약으로 답해 드려요.` | `· 웹 회원으로 연결하지 않고 쓰면 약봉이를 운영하는 분이 등록한 약과 상담 기록을 볼 수 있어요.` | `· 웹 연결은 ‘연결 끊기’로 끊어요. 연결하지 않고 쓰다 기록을 지우려면 약봉이를 알려 준 분에게 말해 주세요.`(지금 `연결을 끊거나 기록을 지우려면 약봉이를 알려 준 분에게 말해 주세요.`는 웹 회원의 `연결 끊기`와 어긋나 바꿈) |

- 그 뒤 호칭 질문은 지금 그대로. 코드는 묻는 어느 단계에서든 먼저 코드로 보고, 맞으면 묻던 값은 버림.

- `끊기`·`취소`는 끊기를 묻는 중에만 그 뜻이고, 그 밖에는 보통 질문으로 넘김(지금 빠른 답장 규칙). `연결끊기`·`연결 끊어`도 같은 뜻으로 받음.
- 웹 연결된 사람의 `도움말` 첫 줄은 `약봉이는 필받음 웹의 ‘엄마’ 프로필에 등록된 약과 공식 자료를 바탕으로 답해요.`이고, 목록에 `- 프로필 바꾸기: 다른 가족 프로필 약으로 묻기`와 `- 연결 끊기: 웹 계정과의 연결 끊기`를 더함. `내 약` 첫 줄은 `‘엄마’ 프로필 약이에요.`

## 읽어 주기·접근

- 코드는 한 글자씩 읽히게 이름을 붙임(예: `연결 코드 7 K 3 Q, M 9 X A`). `코드 복사`는 44px 이상.
- 남은 시간은 초마다 읽지 않고, 1분 남았을 때와 시간이 지났을 때만 알림(V3-COMMON-001의 읽기 규칙과 같음).
- 연결됨·끊음·코드 받음은 화면 읽기 프로그램에 한 번 알림.
- 연결 상태는 글자로 씀(색·아이콘만으로 가르지 않음).
- 확인 창은 제목으로 이름 붙인 대화 상자. 열리면 `취소`에 초점, 닫으면 누른 `끊기` 버튼으로 돌아감.

## 공통 규칙

- 말투는 지금 다리 문구(`yakbong/texts.py`)와 필받음 화면의 해요체를 따름.

## 고를 것 2 · 등록 제안에서 고르는 방식(V3-KAKAO-004·005)

글로 한 등록 요청과 처방전 사진이 같은 모양임. 서버 답변 글의 '카드에서 … 확정해 주세요' 문장은 카드가 없는 카톡에 맞지 않아 다리가 아래 말풍선으로 바꾸고, `찾지 못한 이름: …` 줄만 그대로 붙임. 카드 없는 안내(이름 없음·못 찾음·다시 찍기·장애)는 서버 글 그대로임.

| 안 | 모양 | 장단점 |
| --- | --- | --- |
| A | 번호 목록 한 번에: 후보 전체를 이름 묶음별 번호 목록으로 보이고 `모두 등록`(미리 고른 약만)·`1번`·`2번`…·`취소`. 여러 개는 `1 3`처럼 번호를 띄어 보냄. 누르면 바로 확정 | 한 번 눌러 끝나고 말풍선이 하나임. `모두 등록`이 무엇을 넣는지 목록의 ✓를 보고 알아야 하고, 같은 약의 다른 함량을 둘 다 넣을 수 있음(웹 A안과 같은 약점) |
| B | 이름마다 하나 고르기: 미리 고를 수 없는 이름(후보가 둘 이상이거나 함량이 다름)만 하나씩 `1번`·`2번`·`넣지 않음`으로 묻고, 마지막에 넣을 약 요약과 `모두 등록`·`취소` | 웹 카드 B안(DEC-023)과 고르는 법이 같고 한 이름에 한 품목만 들어감. 넣기 전에 요약을 한 번 봄. 헷갈리는 이름이 많으면 그만큼 주고받기가 늘어남 |

- CT 추천: B안. 웹에서 고른 규칙(이름마다 하나, 함량 다른 약을 겹쳐 넣지 않음)을 카톡에도 그대로 두는 편이 안전하고, 보통은 이름마다 함량이 맞는 후보가 하나라 곧바로 요약과 `모두 등록` 한 번으로 끝남. 반론: 함량이 다른 후보만 있는 이름이 여럿이면 질문이 이름 수만큼 늘고, 그사이 30분이 지나면 처음부터 다시 해야 함.

### 두 안 공통

- 미리 고름은 웹과 같음: 이름마다 '함량 일치'이면서 고를 수 있는 후보가 하나뿐이면 그 약.
- 이미 약목록에 있는 후보는 번호 없이 `· 예시서방캡슐 10밀리그램 — 이미 약목록에 있어요`로 보임.
- 약 이름은 기본 이름에 함량을 붙여 씀(`가상정 500밀리그램`, 기본 이름이 없으면 품목명). 함량 배지 대신 `함량 같음`·`함량 다름`·`함량 확인 못 함`을 글로 붙임.
- 마감은 첫 말풍선 첫 줄에 `16:15까지 고를 수 있어요`.
- 다른 지인의 제안은 처리하지 않음: 빠른 답장 글자는 그 지인의 마지막 대기 제안에만 씀.

| 다시 눌렀는데 이미 확정(409 `PROPOSAL_ALREADY_CONFIRMED`) | `이미 넣은 약이에요. 더 넣지 않았어요.` + 처음 넣은 약 목록 |
| 취소 200 | `취소했어요. 약목록에 아무것도 넣지 않았어요.` |
| 취소한 제안(409 `PROPOSAL_CANCELLED`) | `취소한 제안이에요. 넣으려면 약 이름이나 사진을 다시 보내 주세요.` |
| 시간 지남(409 `PROPOSAL_EXPIRED`) | `고를 수 있는 시간(30분)이 지났어요. 약목록에 아무것도 넣지 않았어요. 넣으려면 약 이름이나 사진을 다시 보내 주세요.` |
| 그사이 약목록에 들어감(409 `CONFLICT`) | `고른 약 중 ‘가상정 500밀리그램’이 그사이 약목록에 들어가 있어서 아무것도 넣지 않았어요.` + 남은 후보로 다시 고르기(A안 목록·B안 요약) |
| 404 | `이 제안을 찾을 수 없어요. 약 이름이나 사진을 다시 보내 주세요.` |
| 503·응답 없음 | 제안을 다시 읽어 확정됐으면 확정 200과 같게, 아니면 `지금은 약목록에 넣지 못했어요. 잠시 뒤 다시 눌러 주세요.` |
| 대기 제안이 없는데 `모두 등록`·`취소`·`1번` | 보통 질문으로 넘김 |

### A안

| 말풍선 | 빠른 답장 |
| --- | --- |
| `16:15까지 고를 수 있어요`<br>`‘가상정 500’에서 찾은 약`<br>`1. ✓ 가상정 500밀리그램 · 함량 같음`<br>`2. 가상정 250밀리그램 · 함량 다름`<br>`‘예시캡슐’에서 찾은 약`<br>`3. 예시캡슐 10밀리그램 · 함량 확인 못 함`<br>`· 예시서방캡슐 10밀리그램 — 이미 약목록에 있어요` | — |
| `‘모두 등록’은 ✓ 표시한 약만 넣어요. 다른 약은 번호를 눌러 하나만 넣거나, 여러 개면 번호를 띄어 보내 주세요. 예: 1 3` | `모두 등록` `1번` `2번` `3번` `취소` |

- 미리 고른 약이 없으면 `모두 등록`을 빼고 둘째 말풍선을 `넣을 약의 번호를 눌러 주세요. 여러 개면 번호를 띄어 보내 주세요. 예: 1 3`으로 씀.
- 번호 빠른 답장은 8개까지. 그 뒤 번호는 글로 보냄. 대기 제안이 있을 때 숫자와 띄어쓰기·쉼표만으로 된 글은 번호 고르기로 받음(V3-KAKAO-005의 '글 → 새 턴'에서 이 경우만 뺌).

### B안

| 순서 | 말풍선 | 빠른 답장 |
| --- | --- | --- |
| 고를 이름(미리 고를 수 없는 이름마다) | `16:15까지 고를 수 있어요`<br>`‘예시캡슐’에서 찾은 약이에요. 어느 약인가요?`<br>`1. 예시캡슐 10밀리그램 · 함량 확인 못 함`<br>`2. 예시캡슐 20밀리그램 · 함량 확인 못 함` | `1번` `2번` `넣지 않음` |
| 요약 | `이 약을 약목록에 넣을까요?`<br>`· 가상정 500밀리그램(사진에서 읽은 함량과 맞아 미리 골랐어요)`<br>`· 예시캡슐 10밀리그램` | `모두 등록` `취소` |

- 미리 고를 수 있는 이름만 있으면 곧바로 요약이 나옴.
- `넣지 않음`으로 고른 이름이 있으면 요약 끝에 `넣지 않는 이름: 예시캡슐`을 붙임.
- 모든 이름을 `넣지 않음`으로 고르면 요약 대신 제안을 취소하고 `넣을 약을 고르지 않아 아무것도 넣지 않았어요.`
- 고르는 중에 다른 글이 오면 고르기를 멈추고 그 글을 새 질문으로 받음. 제안은 서버에서 대기로 남아 30분 뒤 끝남.

## 음성(V3-KAKAO-006)

| 경우 | 말풍선 |
| --- | --- |
| 받아씀 | 답의 첫 말풍선 첫 줄에 `🎤 “타이레놀 등록해 줘”로 들었어요.` 그다음은 글로 보낸 것과 같은 답 |
| 1분 넘음(`AUDIO_TOO_LONG`) | `1분이 넘는 음성은 받아쓰지 못해요. 짧게 나눠 보내거나 글로 보내 주세요.` |
| 형식 미지원·받아쓰기 실패·빈 결과·음성 받기 실패 | `음성을 받아쓰지 못했어요. 글로 보내 주세요.` |

- 받아쓴 글을 한 줄 보여 주는 것은 CT가 정함(DEC-019): 잘못 들은 말로 제안이 나와도 지인이 알아챌 수 있게 함. 저장은 어차피 확정 뒤에만 됨.

## 일정 바꾸기(V3-KAKAO-007)

DEC-025(바뀌는 값 먼저)를 말풍선으로 옮김. 서버 답변 글의 '카드에서 … 확정해 주세요' 문장은 다리가 이 말풍선으로 바꿈.

| 경우 | 말풍선 | 빠른 답장 |
| --- | --- | --- |
| 일정 있는 약 | `16:15까지 확정할 수 있어요`<br>`가상정 복용 일정을 바꿀까요?`<br>`바뀌는 값`<br>`· 복용 시간: 07:00 · 12:00 · 18:00 → 08:00`<br>`· 1회 개수: 2개 → 1개`<br>`그대로 두는 값`<br>`· 기간: 11월 1일부터 11월 30일까지`<br>`· 복용 때: 식후`<br>`확정하기 전에는 지금 일정이 그대로예요.` | `일정 바꾸기` `취소` |
| 일정 없는 약 | `예시캡슐에는 지금 일정이 없어요. 이 일정을 새로 넣을까요?` + 네 값 + `말씀하지 않은 값은 기본 일정(오늘 하루, 07:00 · 11:00 · 17:00)으로 채웠어요.` | `일정 바꾸기` `취소` |

| 409 `SCHEDULE_CHANGED`(약 있음) | `제안을 만든 뒤 가상정 일정이 바뀌어서 바꾸지 않았어요. 원하는 일정을 다시 말해 주세요.` | — |
| 409 `SCHEDULE_CHANGED`(약 지움)·대기 제안의 약이 지워짐 | `약목록에서 지운 약이라 일정을 바꾸지 않았어요.` | — |

| 409 `PROPOSAL_EXPIRED`·`PROPOSAL_ALREADY_CONFIRMED`·`PROPOSAL_CANCELLED`·404·503 | 등록 제안과 같은 문장에서 `약목록에 넣지`를 `일정을 바꾸지`로 바꿔 씀 | — |

- 지금 1회 개수가 확인되지 않은 약은 웹과 같이 `-`로 보임.
- 서버 안내 `UNREADABLE`의 '일정을 그만두거나 지우는 일은 복용 달력에서 할 수 있어요.'는 웹에 들어오지 않는 지인에게 맞지 않아, 다리가 이 문장만 빼고 옮김(CT가 정함, DEC-019).

## 연결 해제와 삭제(V3-KAKAO-010)

- 지인에게 보내는 새 말풍선은 없음. 운영자가 `admin unlink`(해제만)·`admin delete`(해제와 기록 삭제)를 실행함. 해제 뒤 그 지인이 말을 걸면 시작 안내부터 다시 나오고 새 프로필로 연결됨.
- 운영자 명령의 출력은 지금처럼 `#짧은키`와 프로필 번호만 보이고 호칭·카카오 키 원문은 보이지 않음.

## 검증 범위

- 목업 캡처: 7장면 × 360 폭(2배). 카카오톡 채팅방을 흉내 낸 정적 HTML이고, 실제 카카오톡의 글꼴·줄바꿈·빠른 답장 가로 스크롤과 다를 수 있음. 빠른 답장은 캡처에서 모두 보이게 줄을 바꿔 그림(실제 앱은 한 줄로 옆으로 밀어 봄).
- 확인한 것: 360 폭에서 말풍선 줄바꿈과 빠른 답장 글자 수(14자 이하).
- 아직 안 한 것: 실제 카카오톡 화면(봇 연결은 운영 서버 다리, 3차 배포 승인 뒤), 화면 읽기, 다크 모드, PC 카카오톡.
